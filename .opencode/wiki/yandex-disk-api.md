## 2. YaDiskDownloader (личный API-путь)

Код: `D:\ПлагиныРевит\YaDiskDownloader` (`strahser/YaDiskDownloader`, ветка `main`,
HEAD `647924c` на 18.11.2026). План: `ProjectsPalns\05-platform\YaDiskDownloader\PLAN.md`.

Зависимости: `aiohttp>=3.9`, `pyyaml>=6.0`, `tqdm>=4.66`; запуск
`.\.venv\Scripts\python.exe src\main.py --config config-k1.yaml`.

Ключи конфига (образцы `config*.example.yaml`):

- `token` — OAuth-токен; `refresh_token` + `client_id` + `client_secret` — опционально,
  токен освежается сам.
- `download_dir` — куда качать (`d:\SsgYandexDisk` у SSG, `d:\YandexProjects` у К1/М1);
  `log_dir` — логи; `chunk_size`, `max_retries`, `workers`, `sock_read`.
- `roots` — корни обхода (`disk:/`, `disk:/К1`, `disk:/М1`);
  `priority` — папки первым делом (внутри — мелкие файлы);
  `exclude_dirs` — технический мусор (`node_modules`, `.venv`, `__pycache__`, `obj`, `bin`, `.git`).
- `repeat_delay_minutes`: `0` — один проход, `>0` — цикл с удвоением паузы до 120 мин
  при проходе без успехов.

Эксплуатация: `watchdog.ps1` держит только `config-ssg.yaml`; К1/М1 — вручную через
`run-manual.ps1` (флаги `-Foreground`, `-Wait`, `-RetryDead`). Зависание 20 минут → exit 2
и перезапуск сторожем. Кэш недоступных файлов — `logs\dead_config-<имя>.json`;
`-RetryDead` откладывает его в `.bak-<дата>`. Разовый стоп — `logs\stop-request.txt`.

**Секреты:** реальные `config*.yaml` и `logs/` в `.gitignore`. Никогда не писать токены
в wiki, планы, чат или коммит; в репозитории только `*.example.yaml`.

## 3. Бизнес-Диск через Алису (ссылка на рабочую инструкцию)

Полная пошаговая инструкция — [`alice-browser-bridge.md`](alice-browser-bridge.md):
проверка `browse status`, чат на `alice.yandex.ru`, промпт с точным путём папки, цикл
«Разрешить один раз» (~25 разрешений на 8 файлов), забор из `disk.360.yandex.ru` через
Downloads с переносом на D и удалением временных копий, инжест в DesignBase, правила
слепого теста НОК. Алиса сама уточняет коды/редакции нормативных документов — поправки
принимать, но перепроверять по тексту PDF.

Запрещённый путь: брать `digest` из ответа `models-v2` (отдаёт зашифрованные ~45 КБ
вместо PDF); `file` в ответе отредактирован релеем, `ckey` меняется каждый запрос.
Проверка скачанного: `head == b'%PDF-'`, `pymupdf.open()` → число страниц и `get_text()`.
